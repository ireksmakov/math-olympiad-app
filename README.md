# ГРАФИКА — тренажёр графиков для ОГЭ и ЕГЭ

Светло-голубой адаптивный сайт на чистом HTML/CSS/JavaScript — **без сервера, базы данных, платных API и установки зависимостей**. Можно открыть `index.html` напрямую либо опубликовать из корня ветки через GitHub Pages.

## Возможности

- Раздельные разделы **ОГЭ (9 класс)** и **ЕГЭ (профиль)**.
- 28 типов заданий с генерацией параметров, каждый раз новые условия.
- Уровни: базовый, средний, сложный. Фильтр по темам.
- Построение двух точек на интерактивной координатной плоскости и автоматическая проверка расположения.
- Автопроверка чисел, отрицательных значений, десятичных дробей с запятой или точкой, обычных дробей вида `3/2`.
- Подсказки и решения; повтор неверных попыток.
- Пробный экзамен: 10 задач, таймер 20 минут, итоги.
- Лаборатория параметра `m` (парабола, модуль, кубическая функция, гипербола).
- Статистика по экзаменам и темам, процент выполняемости, XP, дневная цель.
- Избранное и повтор ошибок. CSV-экспорт.
- Сохранение результатов в `localStorage` браузера (без регистрации и передачи на сервер).
- Удобная адаптация для смартфонов.

## Задания и источники

Задания **авторские, составлены по типам экзаменационных заданий**, а не дословно переписаны из ФИПИ или чужих учебных курсов. Для содержания использованы официальные направления подготовки:

- [ФИПИ: открытый банк ОГЭ](https://fipi.ru/oge/otkrytyy-bank-zadaniy-oge)
- [ФИПИ: открытый банк ЕГЭ](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege)
- [Методические рекомендации ОГЭ, задание 22](https://doc.fipi.ru/oge/dlya-predmetnyh-komissiy-subektov-rf/2026/mr_oge_matematika_2026.pdf)
- [Навигатор профильного ЕГЭ 2026: функции и графики](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/Mat_prof_5_funkcii.pdf)

Исходная ссылка Яндекс Диска пользователя указывает на внутренний `/client/disk/...`, а не на публичный ресурс `/d/...` — содержимое папки **не было импортировано**. Для интеграции нужны общедоступные файлы или публичная ссылка.

## Запуск

Просто откройте `index.html` в браузере. Для разработки удобно использовать `python3 -m http.server 8000` и перейти на `http://localhost:8000`.

## Публикация на GitHub Pages

1. Скопируйте содержимое проекта в **корень** публичного репозитория или отдельной ветки.
2. В GitHub откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, нужную ветку и `/ (root)`.
4. Сохраните. После публикации адрес сайта появится в разделе Pages.

Сайт не требует `npm build` и будет работать на GitHub Pages без сборки.

## Проверка

Запустите `node tests/audit.cjs` — тесты проходят по всем шаблонам с 100 значениями seed, проверяют ответы, область определения, проверку чисел и контрольные математические свойства.

## Ограничения

- Это первая версия с авторскими генераторами задач; **не полный официальный банк ФИПИ**.
- Статистика **локальная**: разные устройства не синхронизируются, преподаватель не видит результаты без выгрузки CSV.
- Проверка построения по двум контрольным точкам **не эквивалентна** экспертной проверке полного рисунка и оформления задания №22 ОГЭ. Сложные развернутые доказательства и параметры, задаваемые ответом в виде интервала, пока не проверяются автоматически.
- Режим экзамена — самостоятельная учебная симуляция, а не официальное пробное тестирование ФИПИ.

## Структура

- `index.html` — оболочка сайта и меню.
- `styles.css` — светло-голубая дизайн-система и адаптивная верстка.
- `app.js` — генераторы, SVG-графики, проверка, статистика, тренировка.
- `tests/audit.cjs` — математические автотесты.
- `favicon.svg` — иконка.
